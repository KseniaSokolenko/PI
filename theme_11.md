### №2. 
Класс итератор с гибкой настройкой и удобными применением
### Ответ: 
```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1

    def __iter__(self):
        return self

    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count


counter = CountDown(6)
for i in counter:
    print(i)
```

### №5. 
Такой же счетчик, как и в первом задании, только это генератор и использует yield
### Ответ: 
```python
def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)
```
